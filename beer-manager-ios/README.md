## V1.5.1 商品增减（2026-10-13）

商品管理提供新增、编辑/调整库存、删除和已删除商品恢复。删除只移出当前业务选项，历史订单、价格、流水保留；仓库、在用酒吧库存及该商品待回空瓶须先处理为零。误删可从“已删除”恢复，同名冲突会提示先改名。库存可直接用减加与快捷按钮调整，修改仍生成库存调整流水。

# 原生 iOS · 啤酒批发管家 V1.4

SwiftUI + Swift Charts，iOS17+，仅苹果系统框架。本地原子 JSON 保存，核心业务在 Core/Repository.swift；首启示例在 Core/Models.swift。五个 Tab 与微信版本对应。

本次最终设计统一深红主色、浅暖灰底色、白色描边卡片和 12pt 圆角；首页与酒吧页强调数字，详情固定四项大操作按钮。送货数量直接点按，售价与包装放在展开项，收款与分种回瓶各自有清楚的单位和核对页。周/月分析包含趋势、排行及上一周期变化，收据使用双列缩略图。原生 AppIcon 已随项目配置。

打开 BeerManager.xcodeproj，选择自己的 Personal Team 和唯一 Bundle ID，连接 iPhone 后 Run。不需要 App Store；免费签名7天后需重新安装签名。具体步骤和已知限制见上级“三端运行说明.md”。2026-10-10 最终版通过通用 iPhone 目标编译（关闭签名）及 16 项业务测试。尚未签名或实体安装；编译通过不能代替真实 iPhone 上的大字模式、键盘遮挡、相册权限和手持操作验收。
