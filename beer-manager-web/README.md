## V1.5.3 业务流程（2026-10-14）

送货按四阶段进行：酒吧与数量 → 货款 → 核对 → 完成。进货、回瓶、收款和盘点按填写 → 核对 → 完成进行。填写、处理货款和核对阶段都明确显示尚未保存，只有点击“确认…并保存”才调用业务 service 写账。

保存后停留在独立结果页，显示本笔业务、酒吧与保存前后的数值变化，并提供查看记录/添加收据和返回详情。其他业务按实际情况另记一笔，送货、回瓶和收款互不强制串联。回瓶默认只登记，也可主动选择按回瓶估算余酒；已经盘点过余酒时使用只登记，避免再次扣减。该商品待回和客户总待回分别显示，空瓶按瓶记录，箱按钮按当前箱规换算。

页面地址包含操作种类和阶段，例如 `#operation/DELIVERY/c-old?stage=fill`。浏览器历史保存本窗口的填写草稿和结果摘要：返回数量页、取消核对、刷新仍保留输入；刷新结果页只读取已保存流水，不重复记账。切换酒吧会重置数量、协商货款及说明，应用新酒吧的专属价格。尚未提交的草稿不属于业务数据，独立窗口或关闭浏览器后不保证恢复，请完成核对保存。

V1.5.3 不改变既有业务数据模型、存储键、云备份或历史账目。静态业务服务继续复用已构建的 `services.js`。离线缓存名称已更新，首访应在线加载新版本。

# 网页 App · 啤酒批发管家 V1.5.3

原生 HTML/CSS/JavaScript，复用小程序 TS 业务 services；不需要框架、npm运行时或业务服务器。

```bash
python3 -m http.server 8767
```

打开 http://localhost:8767。普通静态包首次使用示例账套；正式网站使用 `beer-manager-site`，提供空白账套选择及云备份。正式入口为 https://beer-manager-jm.jacobolivermo.chatgpt.site/app/ 。iPhone Safari → 共享 → 添加到主屏幕。首次在线缓存后支持离线；实际 iPhone 的离线、相册与主屏幕体验待验证。

最终版统一深红主色、暖浅灰背景和白色卡片，五个入口采用细线图标。首页数字优先；送货数量直接点按，价格/包装按需展开，表单底部显示即时合计与错误。确认窗口有固定操作区和滚动明细；客户详情固定四项大按钮。周/月统计按时间汇总，金额图用同轴的送货/实收两组柱形。

业务存于 localStorage，图片存于 IndexedDB。我的 → 导出备份包含全部业务和收据。恢复前有覆盖确认。清理浏览器、换域名或换手机前先备份。小程序、原生 iOS 与本版本数据独立，备份暂不跨端通用。

主要功能：送货、协商价、专属价、分类按瓶回收及库存估算、收款减免、进货盘点、基础资料、流水收据、周月图表。首启使用小程序 Mock。每箱默认24瓶、可调整。

```bash
node tools/build-services.cjs
```
需要 Node 和 TypeScript。可设置 TYPESCRIPT_PATH 为 TypeScript 包绝对路径。services.js 已预先生成，日常运行无需构建。
